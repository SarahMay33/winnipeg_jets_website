# Winnipeg Jets Player Search

A fan-made Winnipeg Jets player search website that allows users to look up players based on their **jersey number, last name, or nickname**.

> **Disclaimer:** This is a completely fan-made project and is not affiliated with, sponsored by, or endorsed by the Winnipeg Jets or True North Sports & Entertainment.

## Features

* Search for Winnipeg Jets players by:

  * Jersey number
  * Last name
  * Nickname
* Displays player information including:

  * First and last name
  * Jersey number
  * Nickname
  * Years played for the jets
* Interactive search interface
* Winnipeg Jets themed design

## Technologies Used

### Current

* **HTML** — Website structure
* **CSS** — Styling and page layout
* **JavaScript** — Search functionality and interactive features

### Planned

* **Java** — Backend development using IntelliJ IDEA
* **MySQL** — Database for storing player information

The long-term goal of this project is to turn it into a **full-stack web application**, with HTML/CSS/JavaScript handling the front end and Java/MySQL handling the back end and player database.

## How It Works

1. Select a search category:

   * Numbers
   * Last Names
   * Nicknames
     
3. Enter or select the information you want to search for.
4. Press the **Search** button.
5. The website searches the player data and displays the matching player's information.
